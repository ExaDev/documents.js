`src/assets/carlito-{regular,bold,italic,bolditalic}.ts` each embed the matching file's bytes, DEFLATE-compressed then base64-encoded, generated by `scripts/generate-text-font-assets.mjs` from the binaries here -- see that script's own header comment for how to regenerate them after replacing these files.

These are ordinary TrueType (`glyf`-based, sfnt version `0x00010000`) fonts, unlike the CFF-flavoured STIX Two Math OTTO font vendored alongside them.
