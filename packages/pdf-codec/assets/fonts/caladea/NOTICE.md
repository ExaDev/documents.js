`src/assets/caladea-{regular,bold,italic,bolditalic}.ts` each embed the matching file's bytes, DEFLATE-compressed then base64-encoded, generated by `scripts/generate-text-font-assets.mjs` from the binaries here -- see that script's own header comment for how to regenerate them after replacing these files.

These are ordinary TrueType (`glyf`-based, sfnt version `0x00010000`) fonts, unlike the CFF-flavoured STIX Two Math OTTO font vendored alongside them.

**Correction to record:** the task that produced this vendoring described Caladea as Apache-2.0 licensed. That is not correct for the actual upstream artifact fetched here. Checked at vendoring time against three independent, authoritative sources -- the `googlefonts/caladea` repository's own `OFL.txt`, the Debian `fonts-crosextra-caladea` package's `debian/copyright` file (`License: OFL-1.1`), and the `google/fonts` catalogue's own directory classification (`ofl/caladea/`, not `apache/caladea/`) -- all three agree Caladea is licensed **OFL-1.1**, not Apache-2.0. No Apache-2.0-licensed distribution of Caladea's actual font binary was found anywhere; fabricating an Apache-2.0 licence attribution for an OFL-1.1 font would misrepresent this asset's real terms, so this notice records the licence actually confirmed against the font, and `OFL.txt` (not an Apache LICENSE file) is what ships alongside it.
